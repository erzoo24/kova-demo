# Kova Coffee Roasters — Operations Demo

A demo web app showing how a small business can replace its order and stock spreadsheets.
All data is fictional; the invoice extraction is simulated.

**Live demo:** https://erzoo24.github.io/kova-demo/

- Dashboard with KPIs, revenue chart and latest orders
- Orders with search, status filters and a status workflow
- Inventory with low-stock alerts and reorder requests
- Invoice import: a supplier invoice is read, matched to stock and added after review

Built with React, TypeScript, Vite, Tailwind CSS and Recharts.

```bash
npm install
npm run dev
```
